# AntiAvg Desktop

Окно и трей для сервиса защиты от усреднения. Ядро не дублируется — используется
тот же `App`, что и в консольной версии, отсюда берутся только его хуки и снимок
состояния.

## Запуск в разработке

```bash
npm install          # в этой папке
npm run dev          # соберёт ядро, скомпилирует main и запустит Electron
```

## Сборка установщика

```bash
npm run dist:win     # NSIS-установщик под Windows -> release/
npm run dist         # Windows + macOS
```

Сборка не подписана. Windows SmartScreen будет ругаться на неподписанный
установщик — для личного использования это терпимо, для раздачи нужен
сертификат Authenticode.

## Как это устроено

```
src/main.ts       окно, трей, IPC, подтверждение остановки
src/guard.ts      обёртка над ядром: запуск, события, снимок состояния
src/settings.ts   настройки; ключи шифруются safeStorage
src/trayIcon.ts   иконки трея рисуются в памяти, без файлов-ресурсов
preload.cjs       мост в окно: contextIsolation, явный список операций
renderer/         само окно (HTML + CSS + JS, без фреймворков)
```

### Хранение ключей

Ключи API шифруются `safeStorage`: DPAPI на Windows (привязка к учётной записи),
Keychain на macOS. На диск в `%APPDATA%/AntiAvg/settings.json` попадает только
шифротекст. Если системное шифрование недоступно, секреты **не сохраняются
вовсе** — окно об этом предупреждает, и ключи живут до перезапуска. Лучше
спросить их заново, чем оставить открытым текстом.

### Остановка защиты

Крестик окна сворачивает приложение в трей — защита продолжает работать.
Остановить её можно только явным действием: кнопкой в окне или пунктом трея,
и оба пути спрашивают подтверждение. Выход из приложения при работающей защите
тоже требует подтверждения.

Это сделано намеренно: охранник, который выключается случайным кликом по
крестику, бесполезен.

### Состояние в трее

| Цвет | Что значит |
|---|---|
| серый | защита остановлена |
| жёлтый | подключение |
| синее кольцо | работает в режиме наблюдения (dry run) |
| зелёный | работает в боевом режиме |
| красный | только что сработала защита |
| оранжевый | проблема со связью |

### Уведомления

При обнаружении усреднения показывается системное уведомление; клик по нему
открывает окно.

## Ограничения

- Пока приложение не запущено, защиты нет. Спящий ноутбук = выключенный охранник;
  для непрерывной работы нужен всегда включённый компьютер или VPS.
- Один экземпляр на машину: второй запуск просто показывает окно первого. Два
  процесса на одном счёте отработали бы один долив дважды.
